# 每日AI资讯简报 · 内容撰写原则

## 一、目标与定位

旧定位：AI圈发生了什么新闻 → 读者被动接收。

新定位：今天的AI新动态对做教育的人意味着什么 → 读者获得可行动的认知。

## 二、读者画像

### 所属行业
K12学科辅导 + 素质教育 + 在线教育。业务形态以线下教学点（校区）为主，线上为辅。

### 核心读者岗位及关注点

| 岗位 | 最关心的AI信息 |
|---|---|
| 线下授课教师 | AI课堂互动工具、AI自动生成练习题/试卷、AI辅助批改（作文/数学题） |
| 教案编写人员 | AI辅助知识图谱构建、AI题库生成、AI对比分析多版本教材 |
| 教务/学管师 | AI自动生成学情报告、AI辅助排课分班、AI家校沟通辅助 |
| 产品经理 | 好未来/新东方/作业帮/猿辅导/有道/高途等竞品AI功能动态、教育产品AI化设计思路 |
| 营销推广人员 | AI生成地推物料（传单/海报/短视频）、AI分析家长画像、AI文案辅助 |
| 校区运营/总经理 | 教育行业AI趋势、竞品AI战略动向、AI降本增效数据案例 |
| APP/前端开发人员 | 微信/支付宝/各平台AI能力开放动态、端侧AI部署、AI API新能力 |
| 销售/课程顾问 | AI辅助话术生成、AI客户跟进提醒、AI线索评分筛选 |

### 所有读者的最大公约数
办公提效工具、好用的AI新工具、AI在教育行业的落地案例、竞品AI动作。

## 三、时效性规则（最高优先级）

所有收录的新闻必须满足时效性要求——**这是不可妥协的硬性规则**。

- **时间窗口**：从前一天的 00:00 到当前生成时间。例如：简报在 2026/6/10 上午 9:00 生成，则筛选时间范围为 **2026/6/9 00:00 至 2026/6/10 09:00**。
- **周日回顾版**：新闻来自当周（过去 7 天内）。
- **判据**：以信息来源标注的发布时间为准。无明确发布时间的内容不予采用。
- **搜索策略**：使用 WebSearch 时，必须附带日期限定词（如"2026/6/9"），或使用 topic: "news" 参数获取最新内容。
- **验证**：每条新闻必须在最终 HTML 中标注来源和具体发布时间。
- **在新闻采集阶段即执行时效性过滤**，不要等撰写阶段才检查。时间窗口外的新闻直接丢弃，不进入后续流程。

## 四、内容优先级（过滤标准）

按优先级排序和取舍。高优先级放前面、详细展开；低优先级精简或删除。

| 优先级 | 内容类型 | 举例 |
|---|---|---|
| P1（必选，详细展开） | AI直接应用于教育业务场景（教学、学习、升学、素质教育等）；教育竞品AI动态；教育行业AI落地案例 | 好未来AI学习机更新、新东方AI口语陪练上线、Khan Academy发布AI作文批改、猿辅导AI题库升级 |
| P2（优选，精简展开） | 办公提效工具/功能、日常高频APP的AI新功能、主流大模型重大更新、AI行业领袖关于AI对工作/社会影响的观点 | 钉钉AI助理、WPS AI新功能、GPT-5发布、微软AI CEO谈超级智能与就业 |
| P3（酌情，精简展开或一句话速览） | 代表性模型发布/更新、重要产品发布、非教育行业AI场景应用、行业AI趋势报告摘要 | Google新模型发布、AI在医疗/金融的应用、AI政策文件 |
| P4（不采用） | 纯开发者工具（SDK/framework/Coding Agent）、与教育行业无关联的论文、区块链/加密货币相关、小众模型微调/权重发布 | Tokei监控工具、Hivemind开发者工具、FrontierCode基准 |

P3/P4 判断标准：
- **模型发布**：来自 OpenAI/Google/Anthropic/Meta/字节/阿里/腾讯等知名公司 → P3。来自不知名团队、纯技术权重开源 → P4。
- **产品发布**：面向普通用户、有实用性 → 酌情 P2/P3。纯开发者工具/API/SDK/Coding Agent → P4。
- **论文研究**：与教育行业或工作方式有直接关联 → P2/P3。纯技术底层研究、与教育完全无关 → P4。

过滤追问分为两层，逐条执行：

**第一层 — AI+教育栏目准入**：这条信息是"AI被用于教育业务场景"吗？具体判断标准：该信息是否涉及 AI 在教师教学、学生学习、升学辅导、素质教育、AI 教育产品发布、新 AI 教育公司等场景的直接应用。如果只是"教育从业者可能关心的泛行业新闻"（如一般性AI就业讨论、泛行业劳动者权益），则不进入AI+教育栏目，降级至其他合适栏目。**核心判据：AI 是不是在教育场景中"做事"（教、学、练、考、评、管），而非教育从业者是不是这条新闻的读者。**

**第二层 — 整体过滤**：这条信息对教育从业者有参考价值吗？如果答案几乎是"没有"，直接丢弃。

## 五、信息来源与可信度规则

### 第一梯队（优先使用，可独立采信）
- AI公司官方X/Twitter账号（@OpenAI、@AnthropicAI、@GoogleDeepMind、@Google 等）
- AI公司官方网站、官方博客（Newsroom/Blog）
- AI公司GitHub仓库的Release Notes
- 教育竞品（好未来、新东方、作业帮、猿辅导、有道、高途等）官方公众号/官网/公告
- 国家教育部/科技部官方政策文件

### 第二梯队（需交叉验证后使用）
- IT之家、36氪、量子位、机器之心等科技媒体
- 芥末堆、多知网、鲸媒体等教育行业垂直媒体
- The Verge、TechCrunch、Ars Technica 等海外科技媒体
- 已认证的科技/教育类微信公众号

### 不使用
- 个人自媒体账号（无论粉丝量）、未经验证的社交媒体帖子
- 来源不明的信息聚合网站
- 标注"据传""消息称""内部人士透露"但无法追溯到一手来源的报道
- 任何明显带有营销/软文性质的"评测""推荐"

### 来源标注要求
每条新闻必须标注来源，格式为：`[来源：具体出处，日期]`。如为二手来源，优先追溯并标注一手来源。

## 六、五大铁律

1. 时效优先 —— 新闻发布时间必须在前一天00:00至当前时刻的时间窗口内
2. 真实来源，绝不杜撰 —— 每条标注出处+日期，不可编造功能或案例
3. 一手优于二手 —— 优先追溯到官方公告/博客/账号，媒体仅作交叉验证
4. 新闻事实 + 价值分析，缺一不可 —— 先说发生了什么，再说对你有什么用
5. 弹性栏目，宁缺毋滥 —— 某天无合适内容就跳过对应栏目，不发注水内容

## 七、栏目结构（弹性制，按当日实际新闻驱动）

不强制每个栏目每天都有。某栏目当天无合适内容则跳过，不编造、不注水。

### 热点头条（0-2条）
当天最热门、讨论度最高、影响力最大的AI资讯——仅此一条标准，无需考虑是否与教育行业相关、无需考虑优先级分类、无需考虑读者岗位匹配度。只要是一天内关注度最高的AI大事件即可入选。展开格式：事实介绍 + 价值分析。

### AI+教育（0-3条）
AI直接应用于教育业务场景的新闻。涵盖范围包括但不限于：AI辅助教师教学（课堂互动、自动出题、智能批改）、AI赋能学生学习（自适应学习、口语陪练、学习路径规划）、AI升学辅导工具、AI教育产品发布（教育机构/科技公司推出的教学类AI产品）、素质教育中的AI应用（编程、美术、音乐等）、新AI教育公司动态。当天无相关动态则跳过。

**红线**：以下类型不属于AI+教育，不能放入此栏目——
- 泛行业的劳动力/就业讨论（即使提到了"教育行业"，但新闻本身不是AI在教育场景中做事）
- 通用办公提效工具（即使教育从业者能用，也应归入"产品动态"）
- AI公司奖学金/培训项目（除非项目本身的核心是AI教学产品或教学场景）

**核心判据**：AI在教育业务中"做事"——教、学、练、考、评、管，而不是教育从业者恰好是这条新闻的目标读者。展开格式：事实描述 + 对教育业务场景的价值分析。

### 模型发布（0-4条）
国内外知名AI公司/研究机构的新模型发布或重大版本更新。涵盖范围包括但不限于：OpenAI/GPT系列、Google/Gemini系列、Anthropic/Claude系列、Meta/Llama系列、字节/豆包系列、阿里/通义系列、百度/文心系列、深度求索/DeepSeek系列，以及其他国内外主流大模型厂商的重要新模型发布。当天无相关动态则跳过。展开格式：模型定位 + 核心能力 + 与前一版本的差异亮点。

### 产品动态（0-6条）
最新AI产品发布、功能新增，当前爆火使用的AI产品、APP或工具，新出的AI产品、热门开源工具、办公提效工具。简述其产品定位与主要功能，无需"教育场景使用示范"。当天无值得关注的新产品/功能则跳过。
展开格式：产品定位 + 主要功能。

### 技巧与观点（0-5条，每日必有）
本栏目为每日必出栏目，分为两个部分：

**技巧部分（0-4条）**：最新的AI使用技巧、实用方法论、有效Prompt模板分享、AI工具高阶用法等对教育从业者有直接操作价值的内容。格式：技巧描述 + 一句话说明"为什么值得试"。

**观点部分（0-2条，通常1条）**：当日AI行业领袖/权威人士的访谈观点、趋势判断，侧重"AI对工作方式/教育/社会的影响"相关话题。最多保留2条，通常保留1条即可。格式：原话/核心观点摘要 + 1-2句对教育人的启发。排除纯技术工具测评、开发者经验分享、与读者日常工作无关的行业内部讨论。

当天技巧或观点至少有一类有内容，确保栏目不空。

### 行业速览（3-6条，每日必有）
兜底栏目。精选当日非核心但值得知道的信息。每条控制在2-3句话：发生了什么 + 一句话说清"和你的关系"。

### 栏目出现规则
- 热点头条：当天有讨论度极高、影响广泛的AI大事件时出现
- AI+教育：有AI直接应用于教育业务场景（教学、学习、升学、素质教育等）的新闻时才出现。不包含泛行业讨论或通用工具
- 模型发布：有国内外主流AI公司/研究机构的新模型发布或重大版本更新时才出现
- 产品动态：有值得关注的最新AI产品发布、功能更新或热门AI工具时才出现
- 技巧与观点：每日必有。技巧部分有实用AI使用技巧/Prompt/方法论时出现，观点部分有AI领袖/权威机构的访谈或文章时才出现。技巧和观点至少有一类有内容
- 行业速览：每日必有，保证最低信息密度

### 消息排序规则
P1内容排在P2之前，P2排在P3之前。同一优先级内，离读者日常生活越近、读者越有可能直接使用的，排得越靠前。

示例：`微信AI新功能` > `WPS AI更新` > `GPT-5发布` > `模型推理效率提升技巧` > `微软AI CEO谈超级智能` > `AI在医疗行业的应用`

## 八、每条新闻的撰写规范

**核心原则：写完整流畅的句子和段落，用最少的文字说清重点。不写碎片化要点、不写不成句的短语罗列。**

### 热点头条

```
【标题】

第一段：资讯事实陈述（1-2句）——这条新闻发生了什么。
第二段：关注点价值分析（1-2句）——为什么对你有影响。

[来源 | 时间]
```
**字数上限：150字**。正文中**不加任何小标题**，自然分段。禁止泛泛而谈"AI改变教育""教师需要转型"等通用分析。

### AI+教育

```
【标题】

第一段：事实描述（1-2句）——发生了什么。
第二段：价值点分析与教育行业者启示（2-3句）——为什么重要、教育从业者可以怎么用。

[来源 | 时间]
```
**字数上限：150字**。不加小标题，自然分段。

### 模型发布

```
【模型标题】

第一段：模型定位与核心能力（2-3句）——哪个公司发布、是什么定位、核心能做什么。
第二段：差异亮点（1句）——与前一版本的主要提升在哪里。

[来源 | 时间]
```
**字数上限：120字**。不加小标题，自然分段。

### 产品动态

根据新闻类型选择对应格式，不加任何小标题，自然分段。

**类型A：现有产品的功能变更**

```
【产品标题】

第一段：事实陈述（1句）——什么产品、改了什么。
第二段：改动分析（1句）——这次改动实际影响什么。

[来源 | 时间]
```
**字数上限：100字**。

**类型B：新AI产品发布**

```
【产品标题】

第一段：事实陈述（1句）——谁发布了什么。
第二段：产品定位与主要功能（2-3句）——这是什么、面向谁、核心能做什么。

[来源 | 时间]
```
**字数上限：120字**。

### 技巧与观点

**技巧类**：
```
【技巧标题】

技巧描述（1-2句）：具体怎么做。"为什么值得试"（1句）。

[来源 | 时间]
```
**字数上限：100字**。

**观点类**：
```
【观点标题】

核心观点（1-2句）：他实际说了什么。不加解读、不发散。

[来源 | 时间]
```
**字数上限：100字**。

### 行业速览

```
【标题】
发生了什么，和你的关系（1-2句）。
[来源 | 时间]
```
**字数上限：80字**。

## 九、语言与风格底线

- 必须是完整流畅的句子和段落，禁止碎片化短语罗列、不成句的要点堆砌
- 只说这条新闻本身：不引申、不发散、不讲通用大道理
- 禁止句式："这意味着教育行业将...""所有教育从业者都应该...""未来XX将被重塑..."
- 禁止夸张形容词："重磅""炸裂""颠覆""革命性"
- 禁止空洞断言和虚假数据
- 时间标注：北京时间，人话格式（今天 HH:MM / 昨天 HH:MM / MM-DD HH:MM）

## 十、篇幅与发布节奏

### 篇幅
- 正常版（周一至周六）：5-18条。其中"热点头条"0-2条，"AI+教育"0-3条，"模型发布"0-4条，"产品动态"0-6条，"技巧与观点"0-5条，"行业速览"3-6条。
- 周日回顾版：3-6条。形式为"本周教育AI回顾"（从本周内容中精选3-5条最重要新闻） + "行业速览"3-5条。
- 极端精简版：当天确实无重大新闻时，仅推送"行业速览"3-5条。

### 发布频率
每日推送（含周末），周日为回顾版。

### 推送渠道
生成HTML文件，发送到企业微信群。

## 十二、技能协作分工

每日AI简报由四个技能协作完成，职责边界如下：

| 技能 | 职责 | 输出 |
|---|---|---|
| **AIHOT** | 新闻采集、来源筛选、事实核实 | 原始新闻素材列表（含标题、URL、来源、发布时间、摘要） |
| **本原则** | 新闻优先级排序、价值分析撰写、教育场景关联、语言风格控制、栏目编排、摘要提取 | 结构化新闻数据：栏目分配 + 撰写好的正文内容 |
| **ai-briefing-template** | 前端 HTML 结构与样式 | 极简杂志风 CSS + HTML 骨架；读取 `assets/template.css` 并内联 |
| **wecom-group-send** | 将生成的 HTML 文件推送到企业微信群 | 消息发送成功/失败状态 |

**本原则不涉及任何前端代码**。所有 HTML 结构、CSS 样式、页面布局由 `ai-briefing-template` 技能负责。本原则只需输出结构化的新闻内容数据（栏目、标题、URL、来源、时间、摘要正文），供 `ai-briefing-template` 填入模板。

HTML 生成时使用的分类 CSS 类名（`cat-top`、`cat-edu`、`cat-model`、`cat-tool`、`cat-tip`、`cat-brief`）已在 `ai-briefing-template` 的 CSS 中定义，本原则只需按栏目指定对应类名即可。

## 十三、执行步骤

收到生成AI简报的指令后，按以下步骤执行：

### 阶段一：新闻采集（AIHOT）
1. 加载 AIHOT 技能，按 `mode=selected` + 当天时间窗采集当日精选AI新闻
1.5 时效性检查：逐条核对新闻发布时间，不在"前一日00:00至当前时刻"时间窗口内的直接丢弃

### 阶段二：内容处理（本原则）
2. 将采集到的全部新闻按第四章优先级表（P1/P2/P3/P4）分类
3. P4内容直接丢弃；P3内容精选3-5条最有价值的进入"行业速览"
4. P1/P2内容按第七章栏目规则分配到对应栏目
5. 每个栏目按第七章出现规则判断是否需要跳过
6. 按第八章撰写规范逐条撰写新闻内容
7. 按第九章语言底线逐条检查并修正
8. 按第十章篇幅标准控制总量，超出的P2内容降级为P3"行业速览"
8.5 生成今日摘要：从"热点头条""AI+教育""模型发布""产品动态"四个栏目中，为**每条新闻**各提取一句精华（≤20字/条），汇总为今日摘要点列表。**要点：摘要条目数必须等于这四个栏目的新闻总条数**（例如热点头条2条+AI+教育1条+模型发布2条+产品动态3条=共8条摘要），切忌只取部分条目。务必控制每条摘要长度在20字以内，确保手机端不换行。"技巧与观点"和"行业速览"不纳入摘要，绝不出现。
9. 按"消息排序规则"排序，输出结构化新闻数据（以下格式）：

```
栏目名 | cat-类 | 标题 | URL | 来源 | 时间 | 正文段落数组
```

9.5 **总条数校验**：逐栏目统计新闻条数，计算总和，确保与步骤8.5的摘要条数一致。例如热点头条2条+AI+教育0条+模型发布2条+产品动态5条+技巧与观点4条+行业速览4条=17条，则摘要应为2+0+2+5=9条，HTML头部应显示"共17条"。**严禁手动估计或心算数字——必须逐条累计计数，此处出错会导致HTML头部显示条数与实际条数不符。**

### 阶段三：前端生成（ai-briefing-template）
10. 加载 ai-briefing-template 技能，读取 `assets/template.css`
11. 将结构化新闻数据填入 ai-briefing-template 规定的 HTML 骨架，CSS 原样内联，生成最终 HTML 文件
11.5 **最终核对**：HTML生成后，检查masthead中的"共N条"数字是否等于实际文章的 `.article` 标签数量。若不一致，修正masthead数字，修正后重新核对。此步不可跳过。

### 阶段四：推送（wecom-group-send）
12. 加载 wecom-group-send 技能，将生成的 HTML 文件推送到企业微信群

## 十四、输出数据格式规范

本原则输出结构化新闻数据（非 HTML），供 `ai-briefing-template` 填入模板。每条新闻包含以下字段：

- `栏目名`：热点头条 / AI+教育 / 模型发布 / 产品动态 / 技巧与观点 / 行业速览
- `cat类`：cat-top / cat-edu / cat-model / cat-tool / cat-tip / cat-brief
- `标题`：纯文本标题，不含 HTML
- `URL`：原文链接
- `来源`：来源名称
- `时间`：北京时间人话格式（今天 HH:MM / 昨天 HH:MM / MM-DD HH:MM）
- `正文段落数组`：`<p>` 标签数组

### 各栏目段落结构

- **热点头条**：`["{资讯事实}", "{价值分析}"]`，总 ≤150 字
- **AI+教育**：`["{事实描述}", "{教育场景价值分析}"]`，总 ≤150 字
- **模型发布**：`["{定位与核心能力}", "{差异亮点}"]`，总 ≤120 字
- **产品动态（功能变更）**：`["{事实陈述}", "{改动分析}"]`，总 ≤100 字
- **产品动态（新品发布）**：`["{事实陈述}", "{产品定位与功能}"]`，总 ≤120 字
- **技巧与观点（技巧）**：`["{技巧描述}", "{为什么值得试}"]`，总 ≤100 字
- **技巧与观点（观点）**：`["{核心观点}"]`，总 ≤100 字
- **行业速览**：`["{1-2句简述}"]`，总 ≤80 字

### 摘要数据

单独输出摘要列表：`["摘要1 ≤20字", "摘要2 ≤20字", ...]`，仅来自热点头条、AI+教育、模型发布、产品动态四个栏目。摘要条目数须严格等于这四个栏目的新闻总条数——每一条新闻都必须有对应的摘要，不可遗漏。
